# Aerial object classification & detection — Bird vs Drone

Capstone implementation for **binary aerial image classification** (Bird / Drone) using **PyTorch** (Custom CNN + transfer learning baselines), optional **YOLOv8** object detection, a **Streamlit** app for interactive inference, plus **reports/figures** for evaluation.

> **Why PyTorch (not TensorFlow)?** This environment uses **Python 3.14**, and TensorFlow/Keras does not currently ship wheels for it. The capstone brief allows **PyTorch** as an alternative.

## Reproduce everything (full pipeline)

These are the same steps as “Start here”, but include training commands if you want to regenerate checkpoints.

1. **EDA & statistics**

```bash
export PYTHONPATH=.
python run_eda.py
python statistical_analysis.py
```

2. **Classification training**

- Train one model:

```bash
python train_classification.py --model resnet50 --epochs 25 --batch-size 32
```

- Train all models:

```bash
python train_all_models.py --epochs 25
```

3. **Evaluate on test split**

```bash
python evaluate_classification.py
python plot_training_curves.py
```

4. **YOLOv8**

```bash
python convert_coco_to_yolo.py
python train_yolo.py --epochs 40 --imgsz 416 --batch 16
python evaluate_yolo.py
```

5. **Streamlit**

```bash
streamlit run app.py
```

## Data handling (how labels are created)

- **Classification labels**: derived from COCO at the **image level** by majority label across annotations. Images with **no** annotations are skipped for classification (see `bird_drone/coco_manifest.py`).
- **YOLO labels**: one `.txt` per image; an **empty** `.txt` represents “no object” (background) for images without boxes.
- **Class imbalance**: training uses **weighted cross-entropy** computed from the training split.

## Metrics & model selection

- **Classification**: checkpoints selected by **validation F1** (positive class = drone). Reports include **test accuracy**, sklearn classification reports, and confusion matrices.
- **Detection**: Ultralytics **mAP50** and **mAP50-95** (see `outputs/reports/yolo_validation_summary.md`).
