This folder is generated by the training/evaluation scripts.

If you're evaluating the project, start by opening:

- reports/model_comparison_classification.md
- reports/statistical_analysis.md
- reports/yolo_validation_summary.md
- figures/ (EDA plots, confusion matrices, training curves)

Key paths:

- classification_manifest.csv
  - Image paths + labels for train/valid/test (derived from COCO annotations).

- classification/<model>/
  - Trained checkpoints + metadata.
  - Most important file: best_model.pt

- reports/
  - model_comparison_classification.md
  - classification_report_<model>.txt
  - statistical_analysis.md
  - yolo_validation_summary.md

- figures/
  - eda_*.png
  - confusion_*_test.png
  - training_curves_*.png
  - streamlit_app_preview.png (static UI reference image)

- yolo/train/weights/
  - YOLOv8 weights (best.pt) after running train_yolo.py

Streamlit:

- Run from project root: streamlit run app.py
- Open: http://localhost:8501

Note: Git may ignore large files (outputs/ and *.pt). For grading/submission, zip the project including outputs/ if required.
